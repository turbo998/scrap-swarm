# 《废土斗机祭》角色与机体设计圣经

## 总体视觉规则

- **关键词**：维修胜过炫耀、工业件转化为武术姿态、非对称、可见关节、可读损伤。
- **禁区**：不使用经典白蓝红英雄配色、额头 V 形天线、武士面罩、盾枪标准轮廓或任何可识别的既有机甲符号。
- **游戏尺度**：玩家约 55–70 px 高，普通敌人 30–55 px，Boss 120–150 px 宽。第一识别来自轮廓，第二来自运动，最后才是颜色。
- **材质**：搪瓷旧漆、氧化钢、油污橡胶、黄铜接头、磷光玻璃。所有亮光均对应传感器、炉心或危险信号。
- **共同标识**：绿溪采用断开的圆环加三条维修刻度，表示“系统可以被打开、检查和修复”；不是军徽。

## 01 R-17「锻火拳」

### 角色功能

自主维护机器人、绿溪代表、唯一玩家角色。视觉核心是“把修路工具当成武术架势”，而非传统人形士兵。

### 轮廓与比例

- 头部 1、躯干 2、履带底盘 1.1，总高约 4.1 个头部。
- 左侧高耸排气背包，右侧长工具臂，形成强非对称。
- 身体重心低，肩窄、前臂大；正面像准备架拳的维修台车。
- 不加双腿，保留现有双履带 rig；转向靠履带差速，攻击靠躯干扭转。

### 色彩与材料

| 用途 | 色值 | 材料 |
|---|---|---|
| 主装甲 | `#74775C` | 褪色橄榄搪瓷 |
| 内骨架 | `#282B24` | 油黑钢 |
| 工具警示 | `#D79A3B` | 磨损黄漆 |
| 视觉传感器 | `#B9DD78` | 绿色磷光玻璃 |
| 维修标记 | `#E6D7A8` | 手刷浅色漆 |

胸甲右下保留红、绿双状态灯；左下绘断环维修标识。R-17 编号牌故意歪装，表示岚使用了不同年代的四枚螺栓。

### 结构

- **头**：窄矩形护目镜，单条光带向移动方向偏移；细天线只负责无线电，不形成 V 字。
- **右臂**：三段关节工具臂，前端为爆铆拳炮；炮口像冲击扳手，不像步枪。
- **左臂**：较短的磁场线圈护臂，概念图中作为震磁圆阵发生器；游戏小尺寸可省略为肩侧线圈。
- **背部**：竖直排气罐、卷线盘、可拆电池槽。
- **底盘**：双履带、两枚大承重轮、前低后高；侧面可见张紧器。

### 动作表达

- **待机**：压缩机轻微起伏，天线搜索，右拳炮下垂后重新锁紧。
- **移动**：履带齿错位滚动，躯干逆向抵消；高速时背包排出短促尘烟。
- **攻击**：爆铆拳炮先后坐再前冲，像直拳；震磁圆阵由左臂向外展开；雷索从肩部卷线盘甩出。
- **受击**：护目镜由绿转琥珀，胸甲偏转并喷出 3–5 根短火花。
- **低血量**：左履带偶发抖动，排气加重，但轮廓和控制反馈不改变。

### 正 / 侧 / 背

- **正面**：突出歪编号牌、右大左小手臂和宽履带。
- **侧面**：头部前探 8°，背包高于肩，拳炮与履带前缘对齐。
- **背面**：中央检修舱、外露软管、绿溪断环标识和岚的手写扭矩数据。

## 02 岚·韦斯

### 角色功能

人类机械师、无线电搭档、维修棚负责人。只出现在设定页、标题/通讯肖像和 UI，不进入竞技场，也不成为玩家角色。

### 轮廓与服装

- 身高约 168 cm，偏瘦，长期搬运形成结实前臂。
- 大号非对称焊接披肩从左肩垂下，右臂保持灵活；腰间工具包形成锯齿轮廓。
- 短发一侧剃短，另一侧用铜线束起；不使用军帽或驾驶服。
- 护目镜常停在额头，镜片一绿一琥珀，对应诊断与焊接模式。

### 色彩与材料

- 工作服 `#454B3A`，披肩 `#8E5735`，内衬 `#D5C69B`，护目镜 `#B9DD78 / #E6A747`。
- 衣物补丁不是装饰：胸前白线记录绿溪水泵检修次数，左袖三道橙线对应三次停电事故。

### 肖像表演

- **正常通讯**：身体朝设备，眼睛看向玩家，强调她同时工作和交流。
- **紧张**：握住耳机线而非夸张尖叫。
- **鼓励**：抬起扭矩扳手，用“准备一起修”的姿态替代胜利手势。
- **失败**：先看遥测，再看镜头，表现“确认伙伴仍在线”。

## 03 铁冠·赫克托

### 角色功能

冠军工业机、理念宿敌、唯一 Boss。曾是矿井救援平台，因此其压迫感来自过度强化的救援机械，而非贵族骑士造型。

### 轮廓与比例

- 宽度约为 R-17 的 2.4 倍，高度约 1.7 倍。
- 巨型连续履带为水平基座；上方是窄头舱和两支活塞臂，像移动液压机。
- 肩部不对称：左侧保留救援探照灯，右侧装竞技冲锤。
- “铁冠”不是头冠，而是胸前环形专有锁具，由六枚粗螺栓围住炉心。

### 色彩与材料

- 烧黑钢 `#25241F`、旧矿铜 `#735338`、危险橙 `#E0A044`、炉心红 `#D65B35`。
- 原救援编号被联盟黑漆覆盖，受击后露出“救援优先”的旧字样，为反转提供视觉伏笔。

### 动作表达

- **待机**：活塞交替加压，胸锁每两秒收紧一次。
- **移动**：履带缓慢但不停止，躯干几乎不晃，表达不可退让。
- **攻击**：双臂先向外张开再夹击；召唤增援时探照灯扫过场地。
- **受击**：装甲只小幅偏移，炉心环出现不同方向的裂光。
- **败北**：胸锁碎裂、探照灯转为稳定白光，主体不爆炸，保留其作为证人的合理性。

“胸锁碎裂”是胜利结算与概念分镜中的造型状态，不是当前游戏里的独立部位破坏、瞄准或终结技系统。

### 正 / 侧 / 背

- **正面**：胸锁、五枚履带轮和窄橙色观察窗构成识别。
- **侧面**：长履带、短上身、后置液压储罐。
- **背面**：旧救援绞盘、可展开担架接口、被封死的公共数据端口。

## 04 赤砂牙轮

- **功能哲学**：联盟把“可维修”改造成“一次性消耗”。
- **轮廓**：低矮椭圆躯体、六条长腿、左侧旋转齿轮；约 34×28 px。
- **色彩**：锈红 `#6F3827`、暗钢 `#282824`、琥珀眼 `#F0A34A`。
- **结构**：腿根是可替换夹具，齿轮原为切割路面裂缝的工具。
- **动作**：待机时腿尖逐个敲地；移动为交错三足步；攻击时齿轮先空转再扑击；受击时腿向内收缩。
- **视图要点**：正面突出齿轮偏置；侧面像贴地昆虫；背面显示被焊死的维修盖。

## 05 铁壁角斗机

- **功能哲学**：把防护误解为拒绝改变。
- **轮廓**：方形压缩舱、短履带、两支外伸液压撑臂；约 58×52 px。
- **色彩**：褐铜 `#745038`、履带黑 `#20211D`、横向警示黄 `#C49543`。
- **结构**：躯体来自废料压缩机，正面横条是原安全挡板。
- **动作**：待机时左右活塞不同步；移动呈沉重两段式；攻击时撑臂落地、舱体前冲；受击只在焊缝处闪光。
- **视图要点**：正面近方形，侧面前低后高，背面有压缩废料出口。

## 06 苍雷浮游卫

- **功能哲学**：远距离控制看似干净，仍会把代价留给地面的人。
- **轮廓**：中央圆形传感器、两片不对称散热翼、下方无腿；约 52×42 px。
- **色彩**：冷灰绿 `#56625C`、深芯 `#28302E`、电光 `#B9F4C9`。
- **结构**：中央原为气象雷达，散热翼由路牌铝板切割；不使用飞机或人形头部。
- **动作**：待机为不同频率上下浮动；移动时翼片朝反方向倾斜；攻击前外环收紧并闪三次；受击时短暂失衡旋转。
- **视图要点**：正面以同心圆识别；侧面很薄；背面暴露线圈和两根拖曳接地链。

## 游戏内读取优先级

1. 轮廓：履带英雄、昆虫牙轮、方形铁壁、圆翼浮游卫、超宽 Boss。
2. 运动：拳炮后坐、三足步、活塞压缩、悬浮摆动、Boss 夹击。
3. 状态光：绿色玩家、琥珀敌人、冷青远程、红橙 Boss。
4. 小型纹理与标识只服务近景概念页，不依赖其传达战斗信息。
