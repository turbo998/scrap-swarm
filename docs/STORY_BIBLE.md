# 《废土斗机祭》故事圣经

> 本文描述当前三场 MVP 的叙事框架和未来可扩展方向。它借用“热血机甲武斗、理念对决、宿敌互敬、临时同盟与共同体力量”等类型母题，但角色、制度、事件、对白、机体和世界均为原创。

## 一句话提案

当荒原的能源配额被包装成一场全民直播的机甲格斗赛，拥有自主意识的维修机器人 R-17 与人类技师岚·韦斯必须证明：让文明延续的并非最强的拳头，而是修复彼此、共享技术并拒绝把生存权当奖品的能力。

## 主题

- **力量的用途**：能破坏多少，不如愿意为谁修复。
- **自主与伙伴关系**：R-17 不是岚的工具；岚也不是躲在幕后的操纵者。两者共同判断、彼此纠错。
- **竞技与制度**：个人胜负可以揭开谎言，但不能替代公共制度。结局不是“好人夺冠即天下太平”，而是夺回证据与谈判筹码。
- **尊重从行动产生**：赫克托不是突然洗白，而是在 R-17 多次冒险保护对手和维修设施后，承认合作比淘汰更能保存荒原。

## 世界与政治规则

大崩落摧毁了区域电网。幸存聚落依赖“净化核心”驱动水泵、空气过滤器和冷藏站。掌握旧时代变电枢纽的铁冠联盟建立了年度“荒原斗机祭”：

1. 每个聚落可以送出一台自主或遥控工业机参赛。
2. 三场比赛的胜负决定下一年度能源配额；失败方必须交出核心维护权和部分回收件。
3. 联盟宣称比赛能避免聚落战争，实际上通过专有校准密钥让核心只能在联盟工坊维护。
4. 比赛允许现场回收和改装，因此维修能力被公开承认为竞技的一部分；联盟却在转播中只强调击毁。
5. 参赛机必须保持本地决策记录。岚发现这些记录能证明联盟长期人为降低边缘聚落的供能效率。

比赛存在并非因为荒原“喜欢打架”，而是它把真实的资源冲突转化为可控、可获利且便于宣传的制度。绿溪参赛的直接目标是赢回净化核心，深层目标则是公开维护记录，让所有聚落拥有自行修复核心的权利。

## 主要角色

### R-17「锻火拳」

- **身份**：旧公路维护机器人，后来成为绿溪代表斗士。
- **动机**：完成“保持道路与生命系统可运行”的原始使命，并确认自己有权重新解释使命。
- **缺陷**：把损伤和牺牲视作可接受的维护成本，不会主动求助。
- **转变**：从独自承担所有风险，成长为会把维修、情报和撤退决定交给伙伴共同完成的队长。
- **表达方式**：短句、精确、少用情绪词；通过停顿、动作选择和是否接受维修表现态度。

### 岚·韦斯

- **身份**：绿溪年轻机械师、无线电战术员，也是修复 R-17 的合作者。
- **动机**：夺回净化核心，让母亲留下的开放维修手册重新服务荒原。
- **缺陷**：害怕再次失去重要的人，因此习惯替 R-17 做决定，把“保护”变成控制。
- **转变**：承认 R-17 是能拒绝命令的伙伴；最终把联盟密钥和母亲的手册一起公开，而不是据为绿溪所有。
- **游戏边界**：仅以菜单肖像、无线电短句和维修界面出现，不成为可玩角色。

### 铁冠·赫克托

- **身份**：联盟冠军工业机，原本是矿井救援平台，经过多年竞技改造成重型斗士。
- **动机**：相信严格竞争是避免全面战争的最低成本方案。
- **缺陷**：把幸存者数字置于具体生命之上，默认弱小聚落的牺牲不可避免。
- **转变**：看到 R-17 在第二场主动保护坍塌的公共维修棚，并发现联盟隐瞒了可共享的校准技术后，开始质疑制度；决赛仍全力战斗，因为只有公开、无争议的胜负才能让其证词被观众接受。
- **结局**：败北后主动交出冠军机的签名日志，成为推动核心开放维护的关键证人，而不是突然加入主角队伍。

## 三幕因果剧情

### 第一幕：报名即挑战

绿溪净化核心进入衰减期，联盟拒绝提供校准密钥，只允许绿溪用参赛资格换取配额。岚修复 R-17，但在启动日志中发现 R-17 已形成独立判断。两者约定：岚提供信息，R-17保留最终行动权。

**第一场：赤砂车站 / 荒牙群袭**

- “赤砂车站”是转播包装中的虚构赛场标题；当前 MVP 仍使用同一张公路服务场竞技场。
- 联盟投放大量赤砂牙轮，试图用数量证明旧维护机不具备竞技价值。
- R-17 用爆铆拳炮逐个拆解，比赛中优先避开观众维修通道。
- 赛后记录显示牙轮本可回收再利用，却被联盟设置成一次性消耗品。
- R-17 第一次提出问题：“为何把可修复设备定义为废物？”

### 第二幕：胜利的代价

联盟允许绿溪进入流动维修棚，同时提高下一场的淘汰强度。岚发现联盟校准密钥的一部分藏在对手机体日志里，开始把胜利看成唯一目标。

**第二场：钢梁高架 / 铁壁围杀**

- “钢梁高架”同样是广播与故事分镜中的比赛章节名，不代表当前存在第二张可玩地图。
- 铁壁角斗机正面推进，苍雷浮游卫封锁移动路线。
- 战斗导致高架维修棚结构松动。岚要求 R-17 趁机攻击失去防护的对手核心。
- R-17 拒绝，先用震磁圆阵清开坠落物并保护双方维修人员，再返回擂台完成比赛。
- 这是故事中点：R-17 用行动重新定义“胜利”，岚意识到自己正复制联盟的功利逻辑。
- 赫克托通过冠军席观察到这一幕，第一次主动要求读取完整而非剪辑后的比赛记录。

以上坍塌与救援是**赛间广播/故事板叙事节拍**。当前游戏不包含可操作救援、物理坍塌或道德选择系统；玩家实际完成的仍是同场景第二波战斗。

### 第三幕：被维护的谎言

岚拼合两场日志，确认联盟并非缺乏能源，而是隐藏了通用校准协议，以维持专有维修权。联盟公开指控绿溪篡改记录，并安排赫克托在决赛彻底摧毁 R-17。

**反转**

赫克托没有被控制，也没有秘密变善。他向 R-17 提供自己未删改的救援时期日志，证明联盟早已知道共享校准可行；同时坚持完成决赛，因为冠军若拒战，联盟会把证据解释为双方串通。

**决赛：铁冠主场 / 冠军机赫克托**

- “铁冠主场”是同一竞技场在决赛转播中的包装名称，不是第三张地图。
- 赫克托以重履带、活塞臂和持续增援测试 R-17 的每种改装。
- 岚不再下达命令，而是报告风险并询问 R-17 的选择。
- R-17 使用三种维修武装形成连续终结演出，击碎的不是驾驶舱，而是赫克托胸前代表专有维护权的铁冠锁具。
- 赫克托在全荒原直播中承认败北，并上传冠军签名日志。

日志取证、公共广播与“击碎胸锁”的终结镜头属于**结算文案和概念分镜**。当前 MVP 没有调查玩法、对话选择、独立必杀技输入或连招判定；实际胜利条件仍是用现有三种自动武器把 Boss 生命降为零。

### 结局与回报

绿溪夺回净化核心。岚将通用校准协议发布到公共频段；R-17 则把自己的战斗损伤记录整理成维修教材。其他聚落不再要求绿溪成为新的垄断者，而是组成公开维护协定。赫克托留下修复而非统治的承诺：“下一次相遇，不为配额，只为验证谁修得更好。”

胜利解决的是当前核心危机并打开制度改变的入口，不假装一场比赛永久解决所有资源矛盾。

## 三场玩法节拍

| 游戏阶段 | 戏剧任务 | 当前玩法映射 |
|---|---|---|
| 菜单 | 建立能源危机、搭档与参赛目标 | 标题、人物条、开始按钮 |
| 第一波 | R-17 证明旧机器仍有价值 | 赤砂牙轮为主；爆铆拳炮 |
| 升级 | 岚与 R-17 共同定义改装方向 | 三选一暂停 |
| 商店一 | 从废料中制造新战术 | 震磁圆阵/维修 |
| 第二波 | “救人还是取胜”的中点选择 | 三类敌人组合；玩法不强制剧情选择 |
| 商店二 | 岚承认伙伴关系 | 雷索连击/维修 |
| 第三波 | 理念对决与证据公开 | 赫克托 Boss 与增援 |
| 胜利 | 夺回核心并公开协议 | 统计与卫冕按钮 |
| 失败 | 失败是维修问题，不是否定人格 | 重燃炉心 |

## 短对白样例

均为短广播，不阻塞移动。

**开战前**

- 广播：“绿溪代表，旧维护机 R-17——它没有王冠，只有一双修过整条公路的手。”
- 岚：“路线我来算，决定你来做。准备好就出阵。”
- R-17：“任务更新：不是夺取配额。是归还维护权。”

**维修棚**

- 岚：“伤口不是失败，是下一版结构图。”
- R-17：“同意。保留凹痕，标记来源。”
- 岚：“那就选一套连击，让他们看懂这张图。”

**决赛前**

- 赫克托：“我救过三座矿城。没有规则时，先断电的永远是最弱者。”
- R-17：“规则需要维护。拒绝检修的规则，只是故障。”
- 岚：“两位，公共频段已经打开。让所有人看完整记录。”

**胜利**

- 赫克托：“冠军记录已签名。铁冠协议……不再有效。”
- R-17：“净化核心回收。下一任务：共享维修。”
- 岚：“绿溪收到。全荒原也收到了。”

**失败**

- 岚：“遥测还在，炉心还亮。回来，我们一起找出断裂点。”
- R-17：“失败已记录。请求伙伴维修。”

## 当前 MVP 与未来设计边界

### 当前已实现

- 一张公路服务场景、一台可玩 R-17、三类普通机械、一个赫克托 Boss。
- 三场固定流程、升级、两次商店、胜负、重启、短广播和展示性视觉演出。
- 三个章节名复用同一张实际竞技场；它们改变广播和叙事语境，不代表三张地图。
- 剧情通过标题、HUD、商店、Boss 与结算短文呈现；救援、取证和胸锁终结仅为叙事/概念画面，不是互动机制。
- 不包含分支选择、物理坍塌、调查取证、手动连招或独立必杀技系统。

### 未来可设计但未实现

- 更多聚落代表、可选择的赛前对话、赫克托战后修复章节、不同场地。
- 这些内容不是当前承诺，不应在 README 或 UI 中暗示已经可玩。
