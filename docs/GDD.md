# Scrap Swarm / 废铁蜂群 — GDD Lite

## 产品合同

这是一款小规模 PC 浏览器生存竞技场游戏，严格限定为一张地图、一名回收机器人、三把武器、三类普通敌人与一个首领。不包含后端、账号、联网、移动端、局外养成或持久进度。

## 故事背景与角色

大崩落后的第 87 年，军阀“铁冠联盟”垄断能源，并把供电配额包装成面向全荒原直播的巡回机甲赛。绿溪聚落的净化核心被联盟扣押，年轻技师岚·韦斯只能修复废弃维护机 R-17，让它以“锻火拳”的斗士名号参赛。R-17 必须连胜赤砂车站、钢梁高架与铁冠主场三场比赛，击败冠军机“铁冠·赫克托”，公开粉碎联盟“能源只属于强者”的谎言。

- **R-17「锻火拳」**：沉默的旧维护机，以维修工具改造成连击武装；动作笨重但意志表达直接。
- **岚·韦斯**：绿溪技师与无线电教练，负责赛间改装、战术提示和失败后的重启。
- **铁冠·赫克托**：联盟冠军工业机，坚信能源配额应由武力决定，是 R-17 的镜像宿敌。
- **荒原联合广播**：将生存危机包装成娱乐节目，在每场开局播报斗士与场地。

## 核心循环

1. 携带爆铆拳炮进入巡回赛擂台。
2. 移动并风筝敌人，武器自动锁定攻击。
3. 击毁机械后掉落经验与废料。
4. 经验达标时暂停战斗，从三个升级中选择一个。
5. 第一、二场结束后进入绿溪流动维修棚，购买武器或维修，再进入下一场。
6. 第三场生成冠军机赫克托及增援；击毁冠军胜利，完整度归零失败。
7. 胜负结算展示统计，重试时按同一种子重建。

## 视觉与交互

美术由 Phaser 几何图形程序生成：厚重轮廓、暗色钢材、磷光绿、警示橙与冠军机炉心光。敌人不只靠颜色区分。演出层加入每场章标题、无线电台词、横向速度线、R-17 炉心斗气、冠军机放射威压与击破星芒；这些只读取权威状态，不写回玩法，不消耗模拟 RNG。

## 规则与边界

- 玩法以每秒 60 个固定 tick 推进，渲染帧率不能改变权威结果。
- 所有随机生成与升级选择由种子控制。
- 升级、商店、暂停、胜利和死亡阶段不推进战斗。
- 死亡敌人只能结算一次击杀与掉落。
- 测试 API 可预置场景，但 E2E 玩家操作仍使用真实键盘与指针。
- 超时和 Harness 错误不能计为普通死亡。
