原创概念设定集 · 大崩落后第 87 年

废土斗机祭WASTELAND IRON CIRCUIT

能源被包装成擂台奖品时，一台维修机器人选择用战斗证明另一种力量：不是淘汰弱者，而是让所有人都拥有修复世界的工具。

类型：热血机甲竞技 主角：R-17「锻火拳」 主题：维修 / 自主 / 共同体

R-17 三视图

保留履带底盘与维修机器人身份，以右拳炮、左磁场护臂和高位排气背包形成非对称武斗轮廓。

设计标注

01 / 拳炮不是步枪

冲击扳手结构贴近前臂，攻击动作像机械直拳，避免传统持枪英雄轮廓。

02 / 磁场护臂

左臂明显短于右臂，圆形线圈让“防护与推开”成为第二动作语言。

03 / 可维护背面

背部检修舱、卷线盘和扭矩标记必须可见，强调它首先是一台维修机。

04 / 禁用英雄模板

无 V 形冠饰、无面罩、无白蓝红主色、无双足骑士比例。

六组角色设计

每个设计用功能、轮廓和动作表达理念，而不是依赖文化刻板印象或对既有名机的换色。

DESIGN 01 / PLAYER

R-17「锻火拳」

维修不是退路，是战斗目的。

低重心双履带、右拳炮、左磁场护臂与高位排气背包。沉默、自主，会拒绝把伙伴当作可牺牲成本。

非对称维修机直拳后坐
DESIGN 02 / RADIO

岚·韦斯

“路线我来算，决定你来做。”

披肩、工具包和双色护目镜构成轮廓。她只作为通讯肖像与维修伙伴出现，绝不变成隐藏驾驶员。

人类技师无线电开放维修
DESIGN 03 / CHAMPION

铁冠·赫克托

救援机械被制度改造成裁决者。

超宽履带、液压夹臂与胸前专有锁具。败北时锁具碎裂而主体保留，视觉上完成从武器回到救援平台的转变。

理念宿敌矿井救援环形胸锁
DESIGN 04 / SWARM

赤砂牙轮

可维修设备被做成一次性消耗品。

六足贴地轮廓与偏置切割齿轮，移动像急促敲击。被焊死的维修盖是联盟浪费逻辑的直接证据。

六足偏置齿轮高速接触
DESIGN 05 / BULWARK

铁壁角斗机

把防护误解为拒绝改变。

压缩机方舱、短履带与外伸撑臂形成近方形剪影。冲锋前先落臂加压，重量感来自节奏而非单纯放大。

压缩舱液压撑臂重装推进
DESIGN 06 / RANGED

苍雷浮游卫

远程控制仍把代价留在地面。

气象雷达核心、不对称路牌散热翼和拖曳接地链。攻击前同心环收紧三次，给予清晰危险预告。

同心圆薄翼远程电击

关系与理念

冲突不是“正义主角对邪恶坏人”，而是五种维护世界的方法互相施压，最终迫使制度公开接受检修。

岚 · 伙伴而非操纵者从替 R-17 决定一切，成长为提供信息并尊重其选择。
赫克托 · 理念宿敌相信严格竞争能避免战争，最终承认规则也必须被维护。
R-17 · 行动中心以“先修复，再胜利”的选择迫使所有人重新定义力量。
荒原聚落 · 共同体不是等待英雄拯救，而是接收协议、参与公开维护。
铁冠联盟 · 制度压力把稀缺与维修密钥包装成娱乐和服从。

三幕演出板与无线电剧场

游戏内置完整五章《三幕无线电剧场与黑匣子档案》：从第 17 次重启、第二场护卫公共维修棚信标、决赛前夜赫克托未删改的救援日志，到终局广播《公开通用维护协定》。

ACT 01 / 第 17 次重启 · 可修复的骸骨

赤砂车站

旧维护机 R-17 携炉心冲刺（Core Dash）与爆铆拳炮登场，在拆解赤砂牙轮群的同时回收开源维护件，拒绝拆解绿溪老工程机。

ACT 02 / 坍塌高架 · 护卫维修棚信标

钢梁高架

第二场竞技场生成“公共维修棚信标”。R-17 守住信标并在周围迎击铁壁角斗机，触发岚·韦斯的过载支援脉冲与护甲修复。

ACT 03 / 未删改的救援日志 · 铁冠粉碎

铁冠主场

赫克托在三阶段决战中展开双肩排热翼并主动暴露胸前“铁冠锁具”（1.45x 破甲窗口），R-17 击碎锁具后向全荒原广播开源维护协议。

程序化机甲动画架构

零外部图片与音频文件：全部多关节机甲动作、热血番剧切入特写（Anime Cut-in）、冲击帧（Impact Frames）与 Web Audio 合成音效均由代码实时生成，并与 60Hz 固定步长确定性仿真严格解耦。

01 / MULTI-JOINT PROCEDURAL RIG

多部件关节与物理反馈

R-17 具备独立滚动履带轮辐、呼吸起伏躯干、旋转磁盾能量环、液压活塞后坐力回缩、膛口十字闪光、抛壳轨迹与双肩展开散热鳍；首领赫克托具备三阶段变形与高速旋转胸锁。

02 / ANIME CUT-IN & IMPACT FRAMES

番剧演出与 Web Audio 合成

关键节点弹出横向动态矢量立绘切入条（支持 reduced-motion 简化），配合首领击破瞬间的高反差黑白冲击帧与纯 Web Audio API 实时合成的铆钉炮、电磁脉冲与凯旋号角。

03 / 60HZ SEEDED DETERMINISM

固定步长确定性仿真

炉心冲刺（Core Dash）、第二场维修棚护卫信标与第三场铁冠锁具破甲窗口全部运行在无 Math.random() 的种子 PRNG 上，确保无头仿真、渲染模式与自动化测试 100% 一致。
